# A Verdinha — Landing Page Tank-G

Landing page estática pronta para GitHub e Vercel.

## Como publicar na Vercel
1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. Na Vercel, clique em **Add New > Project**.
4. Importe o repositório.
5. Framework Preset: **Other**.
6. Build Command: deixe vazio.
7. Output Directory: deixe vazio.
8. Deploy.

## IMPORTANTE — Links de checkout
Abra `config.js` e substitua:

```js
checkoutBasico: "#",
checkoutProfissional: "#"
```

pelos links reais dos seus checkouts.

## Estrutura
- `index.html` — página
- `styles.css` — visual responsivo
- `script.js` — comportamento
- `config.js` — links de checkout
- `assets/` — imagens

## Observação
Os nomes de marcas/artistas aparecem apenas como referências de timbre. O rodapé comercial da página inclui aviso de não afiliação.
